# v0.17.0 — the house-load forecast becomes a sensor

**New sensor: House Load Forecast** (`sensor.wattsmith_house_load_forecast`).
Since v0.16.0 the planner and the adaptive PV gate forecast the house load from the history DB: per weekday and 15 minutes, over the last 8 weeks, with recent weeks counting more. That forecast stayed inside Wattsmith, so a dashboard could only draw its own imitation of it. The sensor now publishes the planner's own numbers:

- **State:** expected kWh for today (local midnight to midnight).
- **`tomorrow_kwh`:** expected kWh for tomorrow.
- **`forecast`:** every 15-minute bucket from midnight today to the end of tomorrow, as `{"start": local time, "wh": expected Wh}`. It starts at midnight, not now, so a chart can show the forecast for the hours already gone next to what the house actually used. DST days have 92 or 100 buckets.
- **`source`:** `profile` (history DB) or `learner` (the hourly learner plus **Adaptive Baseline Load**, only before a week of history exists). **`profile_days`** and **`window_days`** say how much history it rests on.

The values are the exact function the planner calls for each bucket, not a copy. The `forecast` list (~10 kB) is kept out of the recorder. The state has a state class, so Home Assistant keeps each day's forecast in its long-term statistics, to set against the actual load later.

The forecast is published even when no battery is readable, since the house uses energy either way.
